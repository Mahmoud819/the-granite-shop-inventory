# Repository Guidance

## Project direction
- This is an employee-facing granite, quartz, and countertop inventory tool, not an e-commerce site.
- The app uses Next.js, TypeScript, React, and Tailwind CSS. Keep sample inventory clearly identified until a database is connected.
- Do not put credentials or secrets in client-side code.

## Change expectations
- Keep changes focused and follow established code conventions.
- Add or update focused tests for behavior changes when a test setup exists.
- Document setup and validation commands in the README when project tooling changes.
- Inventory counts and summaries should be derived from inventory records, not separately hardcoded.
